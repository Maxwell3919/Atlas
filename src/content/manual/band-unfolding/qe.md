[QE：pw.x 输入参数](https://www.quantum-espresso.org/Doc/INPUT_PW.html) · [EPW/ZG：bands_unfold.x 输入说明](https://epwdoc.gitlab.io/source/doc/InputsZG.html) · [EPW/ZG：能带展开实例](https://epwdoc.gitlab.io/source/doc/TutorialZG.html) · [QE 7.5：展开程序源码](https://gitlab.com/QEF/q-e/-/blob/qe-7.5/EPW/ZG/src/bands_unfold.f90)

把同一块完美 Si 晶体沿一个原胞基矢重复两次，原子从 2 个变成 4 个。电子结构并没有因此增加一种材料性质，超胞的布里渊区却缩小了，能带图里会出现更多折叠后的支线。要回到原胞的图，除了本征值，还必须读取每个超胞本征态的波函数，判断它在指定原胞 k 点上有多少权重。

这里实际完成了一次 2×1×1 完美超胞校验：原胞、超胞分别重新做 SCF，再沿同一条 Γ–X–W–L–Γ 路径计算能带，最后用 QE 自带的 `bands_unfold.x` 读取超胞波函数。没有引入缺陷或热位移，因此图中恢复出清楚的原胞能带正是应当看到的结果。普通能带的 SCF 与能带步骤可在[能带计算](/Atlas/m/bands/qe/)查看；这一页集中说明超胞映射、谱权重和检验。

[下载本例的输入、原始输出、波函数和绘图脚本](/Atlas/examples/si-unfolding-files.tar.gz)。解压后进入 `si-unfolding`：`python3 analyse_unfold.py` 从两套实际波函数重新核对权重，`python3 plot_unfold.py` 读取表格出图。包内保留两个 `tmp/si.save/`，包括独立复核需要的复波函数；各文件原始与公开版本的 SHA256 见 `manifest.json`。脚本中的 `<qe_bin>` 需换成自己的 QE 可执行文件目录。

## 先让原胞和超胞说同一种坐标语言

结构沿用 [Wannier90 官方 example11 的金刚石 Si](https://github.com/wannier-developers/wannier90/tree/v3.1.0/examples/example11)，晶格常数为 10.2 bohr，即 5.397607551 Å。原胞分数坐标中的 `(-0.25, 0.75, -0.25)` 与 `(0.75, 0.75, 0.75)` 只差原胞平移。本例直接使用该公开结构，并未进行晶格优化。

进入这次保存下来的计算目录，可以看到两条独立的父链：



`primitive/` 存原胞，`supercell/` 存超胞。两个目录分别有自己的 `tmp/si.save/`，不能把超胞输入指向原胞的保存目录。`kpath.csv` 同时记录原胞 k、超胞 K 与沿路径的累计距离，后处理据此核对每一点的顺序。

原胞基矢是 a₁、a₂、a₃，超胞基矢取 A₁=2a₁、A₂=a₂、A₃=a₃。用各自倒格矢表示同一个笛卡尔波矢时，坐标满足 K=(2k₁, k₂, k₃)。下面这几行最容易写错：

| 路径点 | 原胞分数坐标 k | 超胞输入分数坐标 K | 文件点号 |
| --- | --- | --- | --- |
| Γ | 0, 0, 0 | 0, 0, 0 | 1 |
| X | 0.5, 0, 0.5 | 1, 0, 0.5 | 13 |
| W | 0.5, 0.25, 0.75 | 1, 0.25, 0.75 | 19 |
| L | 0.5, 0.5, 0.5 | 1, 0.5, 0.5 | 28 |
| Γ | 0, 0, 0 | 0, 0, 0 | 40 |

这里故意保留超胞输入里的 `1.0`，不自行折回到第一布里渊区。这样波函数的平面波系数与本页使用的投影分量保持一致。若改变 K 的倒格矢代表，同时必须改变用于展开的倒格矢分量选择，不能只把输入数字取模。

## 提交后，从 SCF 的物理信息读到展开文件

本机使用 Slurm；每个作业申请 8 个 MPI 进程，OpenMP 线程数为 1。原胞和超胞各自按 SCF → bands → unfold 串行运行。原胞脚本与下面相同，仅作业名是 `atlas-si-prim`。程序路径在公开文本中写成 `<qe_bin>`，运行时填写本机的 QE 目录。

```text
maxwell@maxwell:<工作目录>/si-unfolding/supercell$ cat run.slurm
#!/bin/bash
#SBATCH --job-name=atlas-si-super
#SBATCH --nodes=1
#SBATCH --ntasks=8
#SBATCH --cpus-per-task=1
#SBATCH --time=00:20:00
#SBATCH --output=_out.%j.log
#SBATCH --error=_err.%j.log
ulimit -s unlimited
ulimit -l unlimited
source /opt/intel/oneapi/setvars.sh
export OMP_NUM_THREADS=1
cd "$SLURM_SUBMIT_DIR"
set -e
mpirun -np 8 <qe_bin>/pw.x -in si.scf.in > si.scf.out 2> si.scf.err
cp tmp/si.save/data-file-schema.xml scf.data-file-schema.xml
mpirun -np 8 <qe_bin>/pw.x -in si.bands.in > si.bands.out 2> si.bands.err
cp tmp/si.save/data-file-schema.xml bands.data-file-schema.xml
mpirun -np 8 <qe_bin>/bands_unfold.x -in unfold.in > unfold.out 2> unfold.err
```

中间保存两份 XML，是因为能带计算会更新同一个 `si.save/data-file-schema.xml`。仅保留最后一份 XML，会丢掉前面 SCF 的 k 网格、总能量和收敛信息。`set -e` 让非零退出码中断脚本；它并不替代对本征值求解、SCF 精度和展开权重的检查。

实际目录保存了 40 个 `wfc*.dat`。这类文件是二进制，不能用 `cat` 读成电子能带。只复制 `si.bands.out` 和 `bands.dat.gnu` 可以重画折叠能量，无法重新求展开权重。

附带的 `analyse_unfold.py` 按 QE 7.5 的 `Modules/io_base.f90` 读取每个波函数文件：记录头、k 点、倒格矢、Miller 整数 hkl，随后每条带的复系数。脚本同时检查 `PW/src/pw_restart_new.f90` 使用的单位：二进制头中的 k 以 bohr⁻¹ 计，XML 的 k 是 2π/alat 单位，比较前须乘回 2π/10.2。它检查文件完整性、点序、标量波函数、非 Γ 压缩格式和 NC 类型，遇到不适用的数据会停止。

对这个 2×1×1 超胞，第一 Miller 整数 h 为偶数的平面波构成目标原胞 k 的分量；h 为奇数的平面波构成另一个分量。对每个超胞本征态直接求和：

<p>W₀ = Σ<sub>h 为偶数</sub> |C<sub>hkl</sub>|²，W₁ = Σ<sub>h 为奇数</sub> |C<sub>hkl</sub>|²。</p>
<p>范数 N = Σ<sub>全部 hkl</sub> |C<sub>hkl</sub>|²；本例应有 W₀ + W₁ = N ≈ 1。</p>

这是对同一个超胞态的两个互补分量求和，不能把某一点所有能带的权重相加后要求等于 1。下面的结果来自原始系数，没有把算出的权重重新缩放到 1：
